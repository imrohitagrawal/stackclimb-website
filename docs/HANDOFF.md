## What this session got wrong, so the next one does not repeat it

Every item here was found by review or by looking at a render, never by the code passing.

- **A gate can assert coverage it does not have, and it reads like proof.** `viewport-reach.spec.js`
  shipped excusing `/` because "its hero is already gated by plate-height.spec.js" — while
  `plate-height.spec.js:40` is `EXEMPT = new Set(['top'])` and `#top` IS the hero. It passed two
  adversarial reviewers, both of whom attacked the assertions and neither of whom read the excuse
  STRINGS as claims. **Review the prose in a test as carefully as its expectations.**
- **A generated artifact can be made to lie by the generator.** `scripts/og-card.mjs` used
  `animation: none`, which froze the practice panel in its PENDING state — the card read `CHECKING`
  beside rows stamped `ENFORCED`, a state the live page never rests in. Fast-forward animations
  (negative delay, 1ms duration); never kill them.
- **Scope a text gate to the region it describes.** The og-card contract first flattened the WHOLE
  page while the card renders `#top` only; 4 of 28 card strings also live in the nav and footer, so
  changing a hero CTA left it GREEN. Demonstrated false acceptance.
- **A manifest regenerated by the thing it checks is circular.** Hiding the CTAs simply dropped them
  from the expectations. Structured region COUNTS plus a generation-time completeness guard fix it.
- **Tie expectations to the shipped bytes.** Regenerating the manifest cleared the red without
  regenerating the image. `pngSha256` is written `null` by the generator and stamped only by
  `npm run og-card:promote`, which actually moves the file.
- **A mutation test that mutates the wrong file proves nothing.** `grep -rln … | head -1` returned
  `experience.astro` and reported a false GREEN. Name the target file explicitly.
- **A local green cannot clear the geometry gate.** 48 of the 51 skips ARE the geometry
  comparisons, skipped under D140 on darwin. CI is the only place they run.
- **Measure the right element.** The og.png palette was called stale by comparing it against
  `#overview`; the card shows `#top`. And a hand-written PNG reader returned palette INDICES as
  grey levels. A measurement that disagrees with everything you know is a bug in the measurement.
- **BSD sed silently no-ops on GNU-only range addresses.** Use Python for scripted edits, and
  grep the file afterwards.
