# DEF-54 — replace the pixel gate's blocking role with a geometry gate

Status: **PLAN, awaiting the owner's approval.** No code is written until he approves,
per AGENTS.md's document-and-get-approval rule. The RCA already exists: DEF-54 in
`docs/STATUS.md`, written before this plan.

## The problem, in one line

The visual gate cannot tell a real layout change from render noise, because on a
type-heavy site the noise **is** text, and no single threshold separates them.

## Ground truth, verified by command

All figures measured 2026-08-24 on committed Linux baselines vs. CI regeneration run
`32711313743`, comparing raw RGB. `plate-proof` is a plate the D112 diff cannot touch, so
any difference there is pure noise; `plate-contact` gained a whole button.

| Fact | Evidence | Result |
|---|---|---|
| Noise exceeds signal at whole-plate scale | raw RGB compare, 1440px | noise **3.17%** vs signal **2.42%** — inverted |
| Raising the per-pixel colour threshold does not separate them | sweep >12 … >120 | noise stays above signal at **every** level |
| Why: the noise is text re-hinting | glyph edges flip `#f2ebdd` → `#1b2440` | a maximal per-pixel delta, not gentle jitter |
| Scoping to the changed row flips the ordering | crop 1000x110 at the CTA row | signal **11.55%** vs noise **6.45%** — only ~1.8x margin |
| The gate passed a wrong baseline | CI run `32707441086` | `plate-contact-1440` passed with a whole new button present |
| The repair path inherited the blindness | `npx playwright test --help` | `--update-snapshots` presets to `changed`; fixed to `=all` in D112 |
| The gate's own stated job is geometric | `tests/visual-baselines.spec.js:24` | *"the nav's layout shifts, a plate's box moves or resizes, or a seam gap changes"* |
| Prior art for numeric gates in this repo | `plate-height.spec.js`, `tap-targets.spec.js`, `file-budget.mjs` | boxes and counts, asserted numerically, no render noise |

**Conclusion this plan rests on:** every item the gate exists to catch is a *number*.
Comparing photographs is a lossy proxy for measuring, and here the proxy is dominated by
noise unrelated to layout. Measure directly.

## What gets built

### 1. `tests/geometry.spec.js` — the new blocking gate

Asserts, per page x width x project, against a committed numeric baseline:

- every `.plate[id]` bounding box: `x`, `y`, `width`, `height`
- the nav's height
- seam gaps between consecutive plates
- for designated structural rows (at minimum `#contact .ctas`): **child count** and each
  child's box

Tolerances: **+/-1px** on measured pixel values (sub-pixel layout rounding is real);
**zero** tolerance on counts. Both stated in the file with the reason.

### 2. `tests/geometry-baseline.json` — a baseline you can read

The decisive property: it is **text**. A PR shows
`#contact .ctas children: 4 -> 5` instead of `Bin 51271 -> 52991 bytes`. A reviewer can
see what changed without opening an image, and git can merge it.

Generated by the same spec under a `--update` path, on any machine, because numbers do
not vary by OS the way anti-aliasing does. **This must be verified, not assumed** — see
acceptance item 5.

### 3. `tests/visual-baselines.spec.js` — demoted, not deleted

Keep the screenshots as a catastrophe net and a human-review artifact:

- raise `MAX_DIFF_PIXEL_RATIO` to a deliberately loose value (**0.15** proposed) that
  cannot fire on hinting noise (worst observed 3.28%) but still catches a blank page or a
  vanished plate
- keep uploading the regenerated PNGs as a CI artifact for eyeballing
- state in the file header that precision is now geometry's job, and cite DEF-54

Two layers, distinct jobs: geometry is precise, pixels are the coarse net.

### 4. Ledger and directives

- DEF-54 moves to fixed, with the measurements above and what remains
- a new `D` row records the decision and the rejected options (threshold tuning: refuted
  by measurement; scoping alone: measured at only ~1.8x margin)
- `gates.yml` updated if the job list changes

## Acceptance — every item is a command, not a judgement

1. **It catches what the old gate missed.** Replay D112's diff (add the copy button) against
   the new gate and prove it goes **red**, naming the CTA row. This is the headline test: the
   gate must catch the exact change that slipped through.
2. **Self-test proves both directions**, in the repo's existing idiom (`--self-test`, as
   `file-budget.mjs` does): a seeded geometry mutation is caught, and the clean tree passes.
3. **Every assertion ships with its RED WHEN line** naming the change that turns it red.
4. **No check that counts nothing.** Each assertion has a denominator proving the thing it
   counted exists — the pattern `contact.spec.js` already uses.
5. **Cross-machine stability measured, not assumed.** Generate the baseline locally and on
   CI and diff them. If any value differs, the tolerance is re-derived from that measurement
   and the finding is recorded. Do not ship a +/-1px claim that was never tested on two OSes.
6. **Full suite green** on CI, and the four D112 contact assertions still pass.
7. **File budget green** — the new spec under 250 lines / 120 chars, `file-budget.mjs` green.
8. **A real regression is caught end to end:** revert the `.contact .ctas` grid rule and
   confirm the gate reports the 390px row-count/geometry change.

## Rejected options, with reasons, so they are not re-proposed

- **Tune `MAX_DIFF_PIXEL_RATIO`.** Refuted by measurement: noise 3.17% > signal 2.42% at
  whole-plate scale. No value orders them correctly.
- **Raise the per-pixel colour threshold.** Refuted by the >12…>120 sweep: noise stays above
  signal at every level, because the noise is text re-hinting, not soft anti-aliasing.
- **Scope the screenshot and keep pixels blocking.** Works (11.55% vs 6.45%) but the margin
  is ~1.8x and every band on this site contains text. Kept only as the loose catastrophe net.
- **Delete visual baselines entirely.** Loses the catastrophe net and the human-review
  artifact for no gain.

## Circuit breakers — stop and escalate, do not push through

Per AGENTS.md, halt implementation and report if any fire:

1. A new class of blocking finding appears in a second consecutive review round.
2. The same defect class appears in two different files.
3. Two fixes in a row each introduce a defect.
4. The change needs three or more amended heads after review starts.
5. The gate misses behaviour an official source documents.

D111 already records three rounds of whack-a-mole on this same file, and DEF-54 is the
fourth failure of that kind. That is precisely why this returns to the contract instead of
patching a number again. **If this plan starts producing rounds, that is the signal to stop
and re-examine the contract, not to iterate harder.**
